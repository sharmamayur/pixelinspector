# Chrome Web Store submission copy

## Product details

**Name:** Pixel Inspector by PixelMonitor

**Summary (132 characters maximum):** See which marketing pixels fire, what data they send, and which visitor action preceded them.

**Category:** Developer Tools

**Language:** English

## Single purpose

Pixel Inspector helps marketers inspect advertising and analytics requests generated by the website journey they perform in the current browser tab.

## Detailed description

See what your website sends to advertising and analytics platforms while you browse it.

When you open the side panel, Pixel Inspector automatically records the journey in the current tab and connects each page visit, click, and form submission to the marketing requests observed afterward. Events are organized by vendor and destination ID, so you can quickly find the pixel you care about and inspect its full payload.

Use Pixel Inspector to:

- Identify supported advertising and analytics requests generated during the journey.
- Connect each request to the visitor action that happened before it.
- Inspect vendor-required fields, website-specific custom fields, and other request fields in one readable view.
- Search by action, vendor, event, destination ID, field name, or field value.
- Keep a separate inspection session for each browser tab.
- Export an HTML pixel report or structured JSON file.

Inspection starts automatically when the panel opens or you switch to a website tab while it is open. It records page addresses, clicked-element labels, form submissions, and recognized marketing request payloads, which may include personal identifiers and purchase details. Recording continues in that tab across navigation and after closing the panel until you Pause, close the tab, or reach the session limit. Clear removes the results and immediately starts a fresh recording. Use Pause to stop capture. Data stays in Chrome session storage for the inspected tab and is not uploaded to PixelMonitor. Pixel Inspector observes browser requests only; it cannot verify server-side events, platform attribution, or final receipt by a vendor.

## Permission justifications

**webRequest:** Observes recognized advertising and analytics requests and their browser delivery outcome so the extension can show which pixels fired.

**storage:** Keeps each tab's inspection data in Chrome session storage through service-worker restarts. The session is removed when the tab closes, the user clears it, or the browser session ends.

**sidePanel:** Displays Pixel Inspector beside the website being inspected.

**scripting:** Injects the click and navigation observer into an already-open page when the extension was installed or reloaded after that page loaded.

**Host access (`http://*/*` and `https://*/*`):** Marketers can inspect any website they manage. Access is needed both to observe actions on the current site and to see its requests to third-party advertising and analytics hosts. Only recognized marketing events associated with an active inspection tab are retained.

## Privacy questionnaire notes

Privacy policy URL: `https://www.pixelmonitor.app/privacy`

Disclose the data handled locally, even though nothing is uploaded by the extension:

- **Web history / browsing activity:** Collected locally because the extension records the origin and path visited in the inspected tab.
- **Website content:** Collected locally because clicked-element labels, roles, and request payload fields are shown in the inspector.
- **User activity:** Collected locally because clicks, navigation, and form submissions are connected to pixel requests.
- **Personally identifiable information:** Request payloads can contain identifiers or customer data supplied by the inspected website.
- **Financial and payment information:** Request payloads can contain transaction IDs, values, currencies, or product data supplied by the inspected website.
- **Location:** Page content and payloads may include addresses, IP addresses, or location fields.
- **Health information, personal communications, and authentication information:** Arbitrary website payloads are preserved without a sensitive-field redaction guarantee, so these categories may also be handled if the inspected website sends them. Do not claim these categories are excluded merely because the extension does not request them directly.

All categories are processed locally to provide the extension's single purpose. They are not sold, used for advertising, or transferred to PixelMonitor. A user may explicitly download an export and decide where to send it.

## Reviewer test instructions

1. Install the extension in Chrome 116 or later.
2. Open a public website that sends an advertising or analytics request.
3. Click the Pixel Inspector toolbar icon. The side panel opens and inspection starts automatically; the data disclosure stays visible.
4. Reload the website to include requests that normally fire during initial page load.
5. Click a link or button on the page.
6. In the side panel, confirm the action appears in **Visitor journey and pixels**. Expand any detected vendor and destination ID, then open **View payload**.
7. Use the search field and its clear button, vendor filter, and Expand all / Collapse all controls.
8. Click **Pause**, then use an export option if at least one event was detected.

No account, payment, credentials, or special test data are required.
